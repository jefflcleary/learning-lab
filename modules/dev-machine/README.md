# Setting up a dev machine

Before you can build things, a computer has to be ready to build with: a proper
editor, a way to run code, version control, and enough of the terminal to move
around. This module gets a machine to that point.

It exists as its own module because the result isn't tied to any one project.
Whatever you go on to build — a game server, a website, a robot — starts from the
same place: a machine you've set up and understand. Other modules assume this one's
result and link back here when they need it.

There's one lesson today, for macOS.

Start with the [recommended path](PATH.md), or go straight to
[Setting up a coding machine](lessons/dev-machine-setup/guided.md).
