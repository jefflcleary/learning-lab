# A recommended path

You don't have to follow this. Every lesson states its own requirements, and if you
meet them you can do it, in whatever order you like. This page exists for the person
who'd rather be handed a sensible sequence than work one out.

## Setting up a dev machine

1. **[Setting up a coding machine](../dev-machine/lessons/dev-machine-setup/guided.md)** —
   a computer that can write and run code: an editor, a JavaScript runtime, and
   version control. This lesson lives in the [Setting up a dev machine](../dev-machine/README.md)
   module because it isn't Minecraft-specific, but it's step one here all the same.
   If an adult is doing this part for you, there's a compressed version for them
   inside; read the main version anyway, so you know what's on your machine and why.
2. **[Running your own server](lessons/running-your-own-server/guided.md)** — a Minecraft server
   you can start, stop, join, and break without consequences. Everything else in this
   module touches this server one way or another.

## The server is yours to change

3. **[The server is yours to change](lessons/server-settings/guided.md)** — read every line of
   the server's settings file and start overruling it.
4. **[Talking to a running server](lessons/console-commands/guided.md)** — the console: change
   the world live, while people are standing in it.
5. **[Changing the rules of crafting](lessons/first-datapack/guided.md)** — your first datapack:
   recipes that shouldn't exist, written in plain text files.
6. **[Teaching the server new tricks](lessons/datapack-functions/guided.md)** — the server acts
   on its own: welcome kits, triggered teleports, things that happen on schedule.

## Letting people in

7. **[The first visitor](lessons/joining-over-lan/guided.md)** — someone else in the house joins
   your world.
8. **[Opening the door to the internet](lessons/joining-from-outside/guided.md)** — friends
   outside the house join a server you run, and use what you built. This is the
   module's central milestone.
9. **[Deciding who gets in](lessons/locking-the-door/guided.md)** — a guest list for an open
   door. Do this the same day as the one above.

## Protecting what people build

10. **[A world is a folder](lessons/worlds-and-copies/guided.md)** — worlds become files you can
    copy, and experiments become free.
11. **[Protecting other people's things](lessons/backups/guided.md)** — a backup script you
    wrote, and proof it works: you'll destroy a world and bring it back.
12. **[Backing up a world that won't sit still](lessons/backups-without-stopping/guided.md)** —
    backups without kicking anyone off.
13. **[A server that's there at seven in the morning](lessons/always-on/guided.md)** — survives
    sleep, comes back after a reboot.
14. **[A history for everything you've built](lessons/git-for-your-server/guided.md)** — version
    control for your datapacks, scripts, and settings.

## Before the bots

15. **[Choosing which Minecraft version your server runs](lessons/choosing-a-version/guided.md)**
    — readable any time, but it matters right here: the next six lessons depend on the
    decision it walks you through.

## First programs

16. **[A player made of code](lessons/first-bot/guided.md)** — a bot joins your sandbox server
    and speaks. Your first program.
17. **[Making it care where you are](lessons/bot-follows/guided.md)** — events, state, and the
    difference between doing a thing and continuously doing a thing.
18. **[Teaching it to take orders](lessons/bot-chat-commands/guided.md)** — a command language
    anyone in chat can use.
19. **[Building something too big to build by hand](lessons/bot-builds/guided.md)** — loops, and
    a pillar through the clouds.
20. **[The bot becomes the referee](lessons/bot-runs-a-game/guided.md)** — your code runs a game
    your friends play start to finish.
21. **[Teaching it to walk](lessons/bot-pathfinding/guided.md)** — the bot navigates real
    terrain, and an old debt gets settled.

## Reading the data

22. **[The server has been keeping a diary](lessons/reading-the-logs/guided.md)** — a second
    language, and a leaderboard mined from the logs.
23. **[A remote control for the server](lessons/rcon-scripting/guided.md)** — your scripts send
    commands to the running server.
24. **[Reading the world itself](lessons/world-data/guided.md)** — binary files give up their
    secrets; a map of everywhere everyone has been.
25. **[Speaking the protocol by hand](lessons/server-list-ping/guided.md)** — bytes on a socket,
    and the answer to how any relay ever knew where to send you.

## Beyond the game

26. **[Two worlds, one conversation](lessons/discord-bridge/guided.md)** — Discord and the
    server become one room.
27. **[A window anyone can open](lessons/whos-online-page/guided.md)** — a live who's-online
    page on the family's phones, built from everything above.

## After that

The last part of this module has no lessons. By this point you have every skill the
list above teaches, and the next project is one you choose and build yourself —
something that doesn't exist yet, for the people on your server.
