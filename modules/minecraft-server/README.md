# Running a Minecraft server

Every Minecraft server you've ever joined is a program running on somebody's
computer. This module puts that program on yours — and then teaches you programming,
networking, and how computers really work by changing everything about it.

The server in this module is not a practice exercise. It's real. Friends and family
can play on it, and everything you learn shows up in front of them:

- You'll add crafting recipes that don't exist in Minecraft — and watch your friends
  discover them.
- You'll open your server to the internet, safely, and someone across town will walk
  around a world running on your machine.
- You'll type one sentence in chat and watch a bot you programmed build a tower
  through the clouds — then referee a full game of hide-and-seek for your friends,
  start to finish, with no human in charge.
- You'll run a modded server that friends join with the unmodified game they
  already have — and later write a mod of your own, with a command you invented.
- You'll read the world's raw bytes and produce a map of everywhere anyone has ever
  walked.
- You'll speak the Minecraft network protocol yourself, one byte at a time, and use
  it to put a live "who's online" page on every phone in your house.
- When something goes wrong — and you will make things go wrong on purpose — you'll
  restore a destroyed world from a backup system you built yourself.

Along the way you'll have learned: the terminal, configuration, JSON, networking
from your wifi out to the internet, backups and version control, JavaScript, Python,
a deliberate first taste of Java,
binary file formats, network protocols, and how to read documentation for tools
nobody taught you. Those aren't Minecraft skills. They're the same ones that run
everything else.

## Where to start

The [recommended path](PATH.md) runs from "set up a machine" to "your code is
infrastructure," in an order where each payoff funds the next. You can also ignore
it: every lesson states its own requirements as facts about your setup, with links
to whatever establishes them, so any lesson whose requirements you meet is fair
game.

New to the lab entirely? Read [how lessons work](../../README.md) and
[how to learn here](../../HOW-TO-LEARN.md) first — they're short, and every lesson
assumes them.

## What you'll need

Different lessons need different things, and each one states its own list. Across
the whole module, the recurring ingredients are: a Mac you're allowed to install
software on, Minecraft: Java Edition with an account that can play it, a home wifi
network, and — for the best parts — friends or family who play. Nothing here
requires paying for hosting; your own machine is the server.
