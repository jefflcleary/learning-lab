# Running a Minecraft server

A curriculum that teaches programming, networking, and computing fundamentals by
running a real Minecraft server and doing things to it. The server is not a toy
example: friends and family can play on it, and the things you build show up in
front of them — custom recipes, bots that take orders in chat, a game your code
referees, a live who's-online page on the phones in your house.

The subject matter is servers, networks, files, and code. The actual point is
bigger: discovering that every system you use is made of parts you're allowed to
open, read, and change.

## Where to start

- **[PATH.md](PATH.md)** — the suggested order, from "set up a machine" to "your
  code is infrastructure." You can ignore it: every lesson states its own
  requirements as facts about your setup, with links to whatever establishes them,
  so any lesson whose requirements you meet is fair game.
- New here entirely? Read [how lessons work](../../README.md) and the
  [learning habits](../../HOW-TO-LEARN.md) first — five minutes, and everything in
  this curriculum assumes them.

## What you'll need

Different lessons need different things, and each one states its own list. Across
the whole curriculum, the recurring ingredients are: a Mac you're allowed to install
software on, Minecraft: Java Edition with an account that can play it, a home wifi
network, and — for the best parts — friends or family who play. Nothing here
requires paying for hosting; your own machine is the server.

## The arc, roughly

Change a running server's settings and rules. Build custom content with datapacks —
no code yet. Let people in: first the same wifi, then the internet, safely. Protect
what they build: worlds as files, backups you've proven, a server that survives
reboots, version control. Then programming: bots, from "says hello" to "referees
hide-and-seek." Then data: logs, remote control, binary world files, a network
protocol spoken byte by byte. And finally out of the game entirely: a Discord
bridge and a web page — at which point you've quietly used most of the ideas that
run the actual internet.
